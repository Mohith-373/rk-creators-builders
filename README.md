# RK Creators & Builders

Official website for **RK Creators & Builders** — a family-run construction business in Thuraiyur, Tamil Nadu, with 25+ years of experience.

## Pages

- `index.html` — Public site (Home, About, Services, Projects, Testimonials, Contact)
- `admin.html` — Private admin panel to add/manage projects and customer feedback

## Tech

Plain HTML, CSS, and JavaScript. No build step required — deploy the folder straight to any static host (GitHub Pages, Netlify, etc.).

## Editing the site

Project data and testimonials are managed through the **Admin** panel (`admin.html`). Any changes made there are stored in the browser's local storage.
